# Portal del Distribuidor Bioclin

Portal estático (un solo `index.html`) para distribuidores de Bioclin en Latinoamérica: documentación regulatoria, documentos del distribuidor y solicitud de compra.

- Publicado en GitHub Pages: https://neimarbiomedicomg-code.github.io/Portal_Distribuidor-/
- Los datos (catálogo, enlaces a OneDrive, cuentas) viven cifrados dentro del archivo. Sin una contraseña válida el archivo no revela nada.
- Administración: entrar como administrador → **Configuración → Publicar cambios** → *Publicar en GitHub Pages* (token fine-grained con permiso Contents: Read and write solo en este repositorio) o descargar `index.html` y subirlo aquí.
